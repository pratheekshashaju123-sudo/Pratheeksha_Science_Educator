DEPLOYMENT
Upload all files to the ROOT of the same GitHub repository / Vercel project.
Do not rename files unless you also update index.html.

The video autoplays MUTED because modern browsers block autoplay with sound.
Visitors can click "Sound on" during the introduction.
After the intro has been viewed once in a browser, the website remembers it.
The visitor can replay the welcome video from the Home section.
